# Погода — OpenWeather (VPd03, авторизация и ключи)

Консольное приложение: вводите город или координаты — получаете текущую погоду.
Ключ OpenWeather хранится только в `.env`, в коде его нет. Ошибки объясняются
человеческим языком, без трейсбеков.

## Возможности

- **Два способа ввода:** по названию города (через Geocoding API) и по координатам.
- **Погода в понятном виде:** `Погода в Москва: 12.4°C, пасмурно`, ниже — «ощущается как»,
  влажность, ветер, координаты и источник данных.
- **Понятные ошибки:** нет ключа, ключ не принят, город не найден, нет сети,
  ответ не JSON — у каждой ситуации своё сообщение и подсказка.
- **Кэш на 3 часа:** последний успешный ответ сохраняется в `weather_cache.json`;
  при сетевом сбое программа предлагает показать сохранённые данные.
- **Повторы:** при `429`, `5xx`, таймауте и обрыве связи — до 3 повторов с паузами
  в 1, 2 и 4 секунды. `401` и `404` не повторяются: смысла нет.

## Установка и ключ

1. Ключ: [openweathermap.org](https://openweathermap.org/) → войти → **My API keys** →
   **Generate**. Новый ключ иногда начинает работать не сразу: от нескольких минут
   до пары часов.

2. Окружение и зависимости:

```powershell
cd Weather_API_progect
python -m venv venv
.\venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

3. Секрет — в `.env` рядом с `weather_app.py`:

```text
API_KEY=ваш_ключ
```

`.env` уже есть в `.gitignore`; в репозитории лежит только `.env.example`.

## Запуск

Самый простой способ в Windows — двойной клик по **`run.cmd`**: при первом запуске
он сам создаст `venv`, поставит зависимости и откроет приложение.

Или вручную:

```powershell
python weather_app.py
```

Если venv не активирован, запускайте через него явно:

```powershell
.\venv\Scripts\python.exe weather_app.py
```

Меню:

```text
1 — погода по названию города
2 — погода по координатам
0 — выход
```

```text
  координаты: 55.7504, 37.6175 · источник: API
  сохранено в weather_cache.json
```

По координатам — пункт 2, обе координаты одной строкой:

```text
Выбор: 2
  Координаты «широта, долгота» (Enter — вернуться в меню): 59.9386, 30.3141

  Погода в Новая Голландия: 6.7°C, пасмурно
  ощущается как 3.9°C · влажность 88% · ветер 4.0 м/с
  координаты: 59.9386, 30.3141 · источник: API
  сохранено в weather_cache.json
```

Название в режиме координат берётся из ответа API — это ближайший населённый
пункт, поэтому оно может не совпадать с привычным названием города.
Разделители координат: запятая, точка с запятой или пробел.

## Ошибки и что видит пользователь

| Ситуация | Сообщение |
|---|---|
| нет `.env` или пустой `API_KEY` | пошагово: где взять ключ и как заполнить `.env` |
| `401` | ключ не принят; напоминание, что новый ключ активируется не сразу |
| город не найден (`[]` в ответе) | «Город «…» не найден. Проверьте написание…» |
| `429` / `5xx` / нет сети | 3 повтора с паузами, затем предложение показать кэш |
| битый JSON или нет `main` | «OpenWeather вернул не JSON / неожиданный ответ» |
| широта/долгота вне диапазона | «Широта должна быть от -90 до 90» и т.п. |

## Кэш

`weather_cache.json` создаётся после каждого успешного запроса:

```json
{
  "city": "Москва",
  "lat": 55.752,
  "lon": 37.6156,
  "fetched_at": "2026-11-15T17:30:00+00:00",
  "weather": { "...": "ответ Current Weather API" }
}
```

При временной недоступности сервиса программа предлагает показать кэш, если записи
меньше трёх часов. Возраст считается по `fetched_at`. Кэш не подменяет свежий запрос:
данные из него показываются только с согласия пользователя.

## Тесты

```powershell
python -m unittest discover -s tests -v
```

Сеть не нужна: `requests.get`, `time.sleep` и ключ подменяются. Проверяются параметры
запросов (`limit=1`, `units=metric`, `lang=ru`), пустой геокодинг, `401`, `404`,
повторы `429`, исчерпание повторов при обрыве связи, форматирование строки,
разбор координат и работа с кэшем.

## Если что-то не работает

| Симптом | Что делать |
|---|---|
| `ModuleNotFoundError: No module named 'requests'` | Запущен Python без venv. Используйте `run.cmd` или `.\venv\Scripts\python.exe weather_app.py` |
| «Не найден API-ключ OpenWeather» | `.env` должен лежать рядом с `weather_app.py` и содержать строку `API_KEY=ваш_ключ` без кавычек и пробелов вокруг `=` |
| `401` сразу после создания ключа | Новый ключ активируется не мгновенно: подождите от нескольких минут до пары часов |
| В консоли вместо русского текст в кракозябрах | Запускайте через `run.cmd` (он включает UTF-8) или выполните `chcp 65001` в PowerShell |
| Хочу проверить, что ключ не утечёт | `git ls-files` не должен показывать `.env`; в `weather_app.py` ключа нет |

## Пункты задания

| Пункт | Где |
|---|---|
| `.env`, `.gitignore` (`.env`, `__pycache__/`, `venv/`) | корень проекта |
| `requests`, `python-dotenv` в `requirements.txt` | `requirements.txt` |
| Загрузка ключа через `load_dotenv` + `os.getenv` | `weather_app.py` |
| `get_coordinates(city) -> tuple[float, float]` (Geocoding, `limit=1`, `lang=ru`) | `weather_app.py` |
| `get_weather_by_coordinates(lat, lon) -> dict` (`units=metric`, `lang=ru`) | `weather_app.py` |
| Ошибки без трейсбеков | `WeatherError`, `_check_status` в `weather_app.py` |
| CLI и строка «Погода в …» | `main`, `format_weather` |
| Режимы 1 / 2 / 0 | `main`, `_run_city_mode`, `_run_coordinates_mode` |
| Кэш с метаданными и сроком 3 часа | `save_cache`, `load_cache`, `cache_age_hours`, `_offer_cache` |
| Повторы 1 / 2 / 4 с при `429` и сетевых ошибках | `_request`, `_wait` |
